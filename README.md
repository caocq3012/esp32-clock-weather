# ESP32 OLED + 四按键测试程序

基于 ESP32 的 SSD1306 OLED 与四个方向按键的测试工程。按下任意按键，
屏幕上会实时显示当前按下的按键名称、总按下次数以及每个键各自的累计次数。
程序使用 millis 时间窗口消抖，不使用 delay 阻塞，方便后续接入天气、NTP 等逻辑。

## 功能特性

- 四个按键 UP / DOWN / LEFT / RIGHT 独立检测
- 软件消抖，默认 50ms，可配置
- 高电平到低电平的稳定跳变才判定为按下，避免抖动重复计数
- 仅在检测到按键时刷新屏幕，减少无意义刷屏
- 上电自动拉低蜂鸣器引脚，避免开机“滴”一声
- 屏幕显示当前按键、总次数、各键次数

## 依赖库

在 Arduino IDE 的库管理器中安装：

- Adafruit SSD1306
- Adafruit GFX Library
- Adafruit BusIO

## 使用方法

1. 按上面的引脚表接好 OLED 和四个按键，按键一端接对应 GPIO，另一端接 GND。
2. Arduino IDE 中选择对应的开发板与 COM 端口。
3. 打开.ino 文件，上传程序。
4. 上电后屏幕显示 OLED OK 和 Press any key，按下任意按键即显示对应按键名。
5. 若屏幕不亮，先用 I2C 扫描程序确认地址，再把代码中的 0x3C 改为 0x3D。
6. 若屏幕显示乱码或花屏，检查 SDA、SCL 是否接反，以及供电是否为 3.3V。

## 消抖原理

程序对每个按键分别记录原始电平和稳定电平。当原始电平发生变化时记录时间戳，
只有当电平保持稳定超过 DEBOUNCE_MS 且与上一次稳定状态不同，才认为发生真实跳变。
其中从高到低的稳定跳变判定为按下。整个过程不阻塞主循环，
因此可以安全地和 WiFi 重连、天气刷新、NTP 校时等逻辑共存。

## 常见问题

**按下按键没有反应**
确认按键是否接 GND 而不是接 3.3V。如果接的是 3.3V，需要把模式改成 INPUT_PULLDOWN，
并把判定条件改为高电平触发。
**按一下跳好几个计数**
把 DEBOUNCE_MS 调大到 80 到 100。如果仍然重复，检查按键是否接触不良或线路有干扰。
**开机蜂鸣器响一声**
代码中已在 setup 里把 BEEP_PIN 拉低。如果仍响，可能是蜂鸣器接线为高电平触发，
需要根据实际电路调整初始电平。
**烧录失败或进不了下载模式**
按住 BOOT 键再点上传，出现连接提示后松开 BOOT。注意 BOOT 键通常接 GPIO0，
不要把它同时接成普通按键，否则上电被拉低会进入下载模式。

## 可扩展方向

- 长按任意键 2 秒调用 ESP.restart() 实现软件重启，比栈溢出崩溃更可控
- 结合 WiFi 状态检测，断线重连后主动重启，避免网络栈异常卡死
- 用 UP / DOWN 切换菜单页，LEFT / RIGHT 调整参数，做成简易设置界面
- 接入天气接口，把温度、天气图标和农历显示在同一块屏上

## 注意事项

- 不要占用 GPIO6 到 GPIO11，这些引脚连接内置 Flash
- GPIO0、GPIO2、GPIO5、GPIO12、GPIO15 属于 Strapping 引脚，上电状态影响启动模式，尽量不接按键
- GPIO34 到 GPIO39 没有内部上下拉，使用这些引脚接按键必须外接上拉电阻
- GPIO1、GPIO3 默认是串口收发，接按键容易和烧录、日志打印冲突
